# QuizCraft
Aplikacja webowa, która na podstawie linku do filmiku YouTube, prezentacji PowerPoint, pliku PDF lub własnego pomysłu, wygeneruje automatycznie za pomocą AI, Quiz na podstawie treści filmu.
